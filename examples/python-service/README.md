# Python service example

This standard-library HTTP service exposes `/health` and `/ready`. Its production
artifact is the executable `build/service.pyz` zipapp generated by the configured
build command.

Run its application checks from this directory:

```sh
python3 -m unittest discover -s tests -v
mkdir -p build && python3 -m zipapp app -o build/service.pyz
python3 build/service.pyz
```

The repository-level documentation shows the complete composition workflow.
